# Provenance

The initial source was the manuscript's existing analysis supplement, updated with its current figure-data tables. Scientific metric implementations were retained; portable entry points replace assumptions about the original directory layout. Original workspace-dependent coordinate and rendering scripts remain in `original_scripts/` for inspection and are not part of the supported reproduction commands.

The manuscript revision used as the starting point was Overleaf commit `b6eff76bb24201cc41a2c16ad9ba96aa0cf098e7`. Figure A12 was promoted to main Figure 4 during this preparation. Figure S10 retains the release-date analysis; Figure S11 retains generated-ligand diagnostics.

Prepared reference hashes are in `references/manifest.csv`. Table regression results are in `validation/table_reproduction.json`. The archived score tables remain unchanged by reproduction.
